# Roadmap

The v0.1 MVP establishes the portable workflow and deterministic integrity substrate. Candidate follow-ups:

- artifact revision commands with explicit supersession and migration diffs;
- strict source-write broker and critical read-only profiles;
- mutation-testing and coverage-policy adapters;
- signed lock roots and CI attestations;
- formal schema validation and version migrations;
- Cucumber message output and framework-specific step-definition adapters;
- pull-request checks for untraced code and weakened assertions;
- semantic spec contradiction and completeness analysis;
- repository reconstruction benchmarks from specs alone.

Strict enforcement should remain opt-in until its recovery and escape-hatch model is proven on real repositories.
